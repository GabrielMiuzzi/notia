# Modelos de voz empaquetados

`scripts/install-speech.sh` crea aquí un perfil verificado antes de compilar. El
instalador descarga Parakeet TDT 0.6b v3 int8, Silero VAD y los modelos de
diarización oficiales, y genera el manifiesto con tamaños y SHA-256. No agregar
otros modelos sin revisar su licencia.
